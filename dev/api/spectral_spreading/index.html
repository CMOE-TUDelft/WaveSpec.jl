Spectral Spreading

WaveSpec.SpectralSpreading.DiscreteSpectralSpreading — Type
DiscreteSpectralSpreading

The discrete realization of a frequency spectrum. Represents the energy distribution across a finite set of frequency bins.

source
WaveSpec.SpectralSpreading.DiscreteSpectralSpreading — Method
DiscreteSpectralSpreading(shape, strategy, fmin, fmax, nf)

Continuous abstract spectrum discretised according to the selected abstract sampling strategy, between fmin and fmax with nf bins.
